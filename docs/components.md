# ET 项目组件包说明

本文档按 `Packages` 下的包组织组件说明。每个包只归纳一个核心职责；包内组件共同围绕该职责提供数据、生命周期或运行时行为。包名和组件名保留代码中的原名，便于在工程中搜索。

## 包级职责

| `cn.etetet.aoi` | 提供九宫格区域感知，用于跟踪实体进入、离开和邻居变化。 | 管理感知区域及区域内实体集合。 |
| `cn.etetet.aspire` | 提供项目与微软分布式运行环境的整合。 | 保存分布式服务编排和运行配置。 |
| `cn.etetet.behaviortree` | 提供行为树运行框架，用于组织可组合的决策逻辑。 | 承载行为树实例、节点执行状态和黑板数据。 |

## 组件索引说明

组件的具体实现仍位于各包的 `Scripts` 或 `Runtime` 目录中。阅读单个组件时，建议先看上表确定包的唯一职责，再看组件所在目录判断客户端、服务端或共享层，最后查看同目录的系统类了解组件的创建、更新和销毁逻辑。

文档统计范围为 `Packages/**/*.cs` 中名称以 `Component` 结尾、或明确继承实体组件基类的类型。自动生成代码、协议模型和测试类型也会被纳入索引；它们属于对应包的实现支撑，不改变包的核心职责。
